# 国际象棋 Chessboard

国际象棋 — Native SDK WebView + Canvas，支持 macOS 与 Windows。**GPLv3**（为后续集成 Stockfish 引擎预留）。

复用 [goban](https://github.com/hxddh/goban)（五子棋）打磨出的整套架构：Native 壳、Canvas 渲染、
侧栏/复盘/主题 UI、双平台 CI、无头浏览器回归测试。

## 下载

[Releases](https://github.com/hxddh/chessboard/releases) 页任选：

| 平台 | 产物 | 说明 |
|------|------|------|
| macOS（Apple Silicon） | **Chessboard-macOS-arm64.zip** | 解压得到 `Chessboard.app`，把它拖进「应用程序」（或 `mv Chessboard.app ~/Applications/`）再打开；首次右键「打开」过 Gatekeeper |
| Windows（x64） | **Chessboard-Windows-x64.zip** | 解压后运行 `Chessboard/chessboard.exe`；需 WebView2 运行时（Win10/11 一般预装） |

## 怎么玩（v1.25）

| 操作 | 说明 |
|------|------|
| **教学模式** | 侧栏「模式 → 教学」：**零基础 72 课**互动课程 —— 认识棋盘七课(坐标 · 浅深格 · 摆法 · 六种子的身价 · 轮流走 · 怎么走一步棋 · 赢是将死) → 六种棋子走法+王的禁区(**每个棋子多套练习:绕障碍/吃子路线/精确落点**) → 子力价值/吃子保护/救受攻的子/捉双/**串击/闪击** → 将军应将(走/挡/**吃**)/**牵制**/将死/逼和/易位/吃过路兵/升变/和棋方式/记谱法 → **杀型积木七课(双车阶梯杀 · 闷杀 · 后车绞杀 · 底线杀 · 后贴脸杀 · 阿拉伯杀 · 博登杀)** → **开局入门八课(三原则 · 第一步为什么是 e4/d4 · 马往中心跳 · 一个子只走一次 · 兵推出去收不回来 · 别拖易位 · 你的第一个开局:意大利)** + **学者杀完整引导局(含防守要点)** → **中局思路(开完局先问三个问题 · 开放线 · 前哨 · 兵型 · 通路兵 · 什么时候该兑子 · 王翼进攻先集结)** → **残局基础八课(方块规则 · 对王 · 关键格 · 错色象 · 车放通路兵后面 · 多子兑子少子兑兵 · 多数兵先推候补兵 · 残局里王是主力)** → **王兵残局(护送升变)**·后杀王·车杀王·**双象杀王**·**卢塞纳(车兵搭桥取胜)**·**菲利多尔(车兵守和,和棋即成功)**·**后对车**实战（**先热身再实战**;引擎陪练用**新手档**会主动犯错,可悔棋/提示）；连错两次自动标答案,「演示」按钮可**随时重看解法**,进度可**重置**,毕业一键进入人机·新手 |
| **做题练习** | 侧栏「模式 → 做题」：**一步杀 / 两步杀 / 三步杀 / 吃子 / 战术母题 / 实战 / 防守 / 求和 / 开局 / 复习**十类题库(**战术题库 168 题 + 开局线路 111 条**)（底线杀、闷杀、肩章杀、阿拉伯杀、达米亚诺杀、升变杀、弃后引杀、双车赶王、**后王/车王逼角、升变三步杀**…）；答错回退并**说明黑方如何化解**;「答案」画正解箭头;杀王题接受任何可强制将死的替代解;吃子题选净得子力最多的一吃;战术母题(**串击/闪将/牵制/捉双**)强制得子;**难度分级(简单/中等/较难)** 由解法长度、子力密度与首着是否安静着自动推导(防守题另按「有几手能接住」定档:只有一手可解的最难),可按难度筛选,筛选结果会记住;开局题执白照谱背 **111 条**主流线路(**其中 71 条是 14–20 手的完整主变**,不再是背五个回合就没了),**每条附思路讲解**;列表按 ECO 排序并标出每条要背几回合;**难度分档按线路长度**(≤4 回合 / 5–8 回合 / ≥9 回合 —— 1.14 之前开局题一律落在「较难」,难度筛选在这一类从来没起过作用);**走错不再只说「这不是谱着」,而是指出违背了哪条开局原则**(送子会点名子力与对方的反击着法,另有王丢易位权/后出太早/同子连动两次/该易位/该出子/该争中心/边兵浪费步数;这一步本身不坏时也照实说不坏);**背完一条线可一键「接实战」**,带着刚背的局面继续与引擎下完这盘;**答错或看答案的题自动进「复习」,需连续两次干净解出才毕业**(间隔重复:中途做错清零,队列按掌握程度排序)；进度持久 |
| 走子 | **点击**或**拖拽**均可。拖动时棋子**被拿起来**：跟随指针、放大并带投影，**指针下的格子画出目标环**（能不能走那儿用不同强度区分），落在走不了的地方棋子**动画回到原格**而不是凭空消失再出现 —— 落子是「指针停在某个 60 像素的格子上」做出的承诺，在此之前不该只能靠松手才知道那是哪一格。**滑动动画只给你没亲手走的那一步** —— 对手的应着(人机引擎、教学陪练、做题对手)会滑过来让你看清它从哪儿到哪儿;你自己点或拖的那一步直接落位,不再从起点重演一遍(拖拽尤其:1.10 之前松手后棋子会先弹回起点再滑一次)。**王车易位王和车一起滑** —— 它是唯一一步动两个子的着法,也是最难看懂的一步 |
| 提和 / 判和 | 「提和」双人双方确认即和,人机由引擎按局面评估接受/拒绝；**「判和」按 FIDE 声明和棋**——同一局面三次重复或 50 回合无吃子无动兵时亮起,五次重复 / 75 回合自动判和 |
| 人机对弈 | 默认与 **Stockfish 18** 对弈；侧栏可选难度（**新手 · 休闲**两档是浅层 MultiPV 抽样的手工削弱档,**用「只会不一步送子」的机器人对下 32 盘量出来:对新手得分率 56%、对休闲 27%、对 Elo 1320 的入门档几乎为零** —— 1.18 之前新手档的 `worstBias` 是 0.6(十个候选里挑最差的那个,六成的着法),同一个机器人能打出 81%,而它上面一格直接就是 1320 · 入门 Elo 1320 · 进阶 1700 · 困难 2200 · 极限**不限档**(不限制棋力等级,搜索仍是 1.2 秒/步 —— 「满强度」这个旧名承诺的是另一件事)）与执子（白/黑，选黑自动翻转视角）；档位强度由 `scripts/test-strength.mjs` 实测把关 |
| 双人对弈 | 侧栏「模式 → 双人」同屏轮流走子；**人机/双人均可开棋钟**（3 / **3+2** / 5 / **5+3** / 10,含**菲舍尔增秒**；超时判负,对方无子力将杀时按 **FIDE 6.9** 判和,含同色象等死局判定）;双人可开**自动翻转**跟随走子方 |
| 点击走子 | 点选己方棋子 → 高亮合法落点（空格圆点 / 吃子圆环）→ 点目标格 |
| 规则 | 完整合法性：将军/将死/逼和、王车易位、吃过路兵、升变（**弹窗选后/车/象/马**）、子力不足自动判和;**三次重复 / 50 回合为可声明和棋（按 FIDE）**,五次重复 / 75 回合自动判和 |
| 提示 | **H** / 顶栏「提示」引擎满强度推荐一着，棋盘上画箭头 |
| 认输 | 棋谱区「认输」结束本局（**双人可选认输方**;人机模式计入统计） |
| 开局 | 侧栏自动显示当前开局名称（内置 **187 条** ECO 库，最深 20 手，复盘时跟随局面）—— 跟着主流主变下,认出的深度实测从第 5.5 手升到第 17.5 手 |
| 分析 | 「分析」快扫(120ms/步) / **「精析」深评(400ms/步)**,**运行中可随时「停止」并保留已算结果**：局势曲线 + `?!` `?` `??` 失着标注 + **引擎主变** + **双方精准度**（跟随复盘位置）；**形势条**——把曲线在当前这一手上读成一根不用看坐标轴的条（复盘限定：对局中不出现，也就不会变成答案表；纯读已算好的数，不占用引擎）；**「该走什么」箭头**——复盘停在一手被标了 `?!` `?` `??` 的着法上时，棋盘直接画出引擎会走的那一步；「重下」从任意一手继续对弈；人机模式可开**失着提醒**（静态预筛,仅在可能丢子时才占用引擎）|
| 复盘 | 着法列表（SAN）点击跳转；← → / Home / End；● 回到最新 |
| **对话框优先于棋局** | 任何对话框打开时,棋局的字母快捷键(P/N/Z/H/F/R)与复盘方向键全部让路,Esc 无论焦点在哪都关得掉——1.11 实测:速查表/存档槽/对局历史开着时 P、F、N 9/9 全部穿透,而升变框因为只能由棋盘操作打开、焦点必然在画布上,Esc 对它**从来没有**生效过 |
| **键盘走子 / 可达性** | 棋盘可 Tab 聚焦：方向键移动光标、回车选子与落子、Esc 取消；每步经 `aria-live` 播报,全程可脱离鼠标操作。**Tab 用于标准焦点移动**(不再被侧栏快捷键占用),所有可聚焦控件都有 **2px 焦点环**,四套主题下与背景对比度实测 4.99–11.56:1。**七个对话框全部是焦点陷阱**:Tab 在框内循环、带 `aria-modal`、Esc 一定关得掉、关闭后焦点回到打开它的按钮(1.9 实测:焦点 4 次 Tab 就走出 FEN 框,而 FEN 输入框把 Esc 一起吞了)。**「减少动态效果」按规范是「减少」而非「关掉」** —— 25 条过渡与动画里,13 条真的动位置或尺寸的(面板平移、棋盘缩放、顶栏重排、模态弹入、两条无限脉动)全部停掉;12 条只做颜色/透明度渐变的保留,因为它们不致眩,而且承担着「轮到谁走」「这题做过了」这类状态反馈。**棋子滑动也一并停了** —— 那是 canvas + rAF 画的,样式表里的媒体查询碰不到,实测滑动帧数 11 → 0,而走子本身照常完成。设置是实时监听的,中途改系统偏好立即生效 |
| **系统集成** | 打开或导出过的 PGN 进 Dock 右键菜单 / Windows 跳转列表（「清除存档」会一并清掉）；**分析在后台跑完时发系统通知** —— 精析 400ms/步，长局要跑半分钟以上，切走之后 toast 是没人看得见的；能力有无一律**问** `platform.supports`（缓存,每种能力只问一次），不再靠「方法存在不存在」猜 —— SDK 对所有平台导出同一套 API，方法永远在 |
| **局面编辑 / FEN** | 棋谱区「编辑局面」摆子开局（棋子调色板 · **按住拖动连续放子** · **右键清除** · 走子方 · 易位权 · **吃过路兵格(仅在真能吃时出现)** · 清空/初始,**合法性实时校验**）；「载入 FEN」从文本或剪贴板载入局面,校验与编辑器同一套规则 |
| **存档槽** | 棋谱区「存档槽」：5 个具名槽位,随时保存/读取/删除,与自动存档并行 —— 研究第二个局面不再冲掉第一个 |
| 棋谱 | 复制 / 导出 / **粘贴导入 / 打开文件 / 拖入窗口导入** PGN（**含多局棋谱库:弹窗选局导入,不再静默只留最后一局**；导出含**标准七标签、TimeControl/Termination 与结果记号**；支持**从指定局面开始**的 `[FEN]` 棋谱,复盘/分析/重下均正确）；复制当前局面 FEN |
| 翻转 | **F** / 顶栏「翻转」切换黑白视角(坐标随之重排) |
| **吃子与子力差** | 双方名条下列出各自已吃掉的子,领先一方带 `+N` 净分差;跟随复盘光标显示当时的对比,而非最新局面 |
| **版式** | 横向窗口左盘右栏;**面板开合时棋盘尺寸立即到位、不做动画** —— 实测收起面板会让棋盘变大 5%(1100×900)、20%(1000×900)、最多 84%(1000×1000,竖高窗口底部抽屉腾出 430px),看着它在四分之一秒里长这么多比直接发现它变大了难受得多;面板自己仍然滑入滑出;**竖高窗口(宽高比 ≤ 1)面板改为底部抽屉**,棋盘吃满宽度与剩余高度(实测 900×1200 下棋盘 604 → 698px);窄窗口面板浮在棋盘上并可点暗区关闭 |
| **陪练风格** | 人机模式下除难度外可选**陪练风格**:标准 / **贪吃子**(见子就吃 —— 实测在「吃了要亏子」的局面里 60% 会上钩,标准引擎只有 13%,你刚学的捉双终于有地方用) / **重原则**(70% 的着法在出轻子,该易位就易位,一次饵都不吃) / **爱进攻**(每一手都落在你王三格以内,平均距离 2.9 对标准的 4.1 —— 专门用来练防守)。风格只在引擎自己的候选着里挑,各有分值上限,绝不送掉已经算到的杀 |
| **快捷键速查** | **?** 打开完整快捷键表(三语);macOS/Windows 另有**原生菜单**:对局(新局/悔棋/提示/翻转)、视图(侧栏/上一手/下一手)、帮助(快捷键),配 ⌘/Ctrl 组合键 —— 桌面用户第一眼会去找的地方不再是空的。**提示是 ⌘⇧H 而不是 ⌘H**:AppKit 先装系统的 app 菜单,其「隐藏应用」占着 ⌘H 且按菜单顺序先命中,1.10–1.17 这一项一直是死的,按下去还会把窗口藏起来(页面内直接按 `h` 不受影响) |
| 悔棋 / 新局 | **Z** / **N**（有棋时确认）；人机模式悔棋会同时收回引擎回着 |
| **首次启动** | 全新安装时问一次「从零开始学 / 我会下棋」——前者直接进教学第 1 课,后者从「入门」难度开局(不再默认 Elo 1700 的「进阶」)；界面语言按系统语言初始化,之后以用户选择为准 |
| **版面比例尺** | 字号 7 档、间距 8 档、**行高 3 档**、字重 3 种、圆角来自 token —— 侧栏 42 处文本的「字号/行高/字重」组合从 15 种收到 11 种,`normal` 行高(随字体而变,中英文在同一列表里节奏不齐)已清零;三行操作链接共用同一组列(实测左缘全部 939/1020/1101,宽高一律 77×35,此前是三种排布加一个孤悬项);模式行与页签用同一套下划线语汇、同为 37px 高(此前是胶囊 35px + 下划线 36px 两套语汇上下贴着) |
| **开局第一屏** | 0 手时对局段不再空着 —— 显示上一局结果、当前难度战绩,以及原本只在「记录」页签出现的那句「接下来做什么」建议(实测空白从 239px/39% 降到 114px/18%) |
| **关窗行为** | macOS 上关窗只是**收起来**,应用还在,Dock 图标点回来接着下(⌘Q 退出);Windows 关窗就是退出。这条不能写在同一份清单里 —— `close_policy` 是逐窗口字段,而 `"hide"` 在 Windows 没有托盘时是**编译期错误**(隐藏会抹掉任务栏项,Windows 没有 Dock 那条回来的路),棋类应用又不该常驻托盘。所以 `app.zon` 保持可移植,macOS 那份由 `scripts/gen-manifest.mjs` 从它派生。**这条 1.18/1.19 写了但没生效**:`src/runner.zig` 是 SDK `app_runner` 的一份分叉,它不读 `close_policy`,于是那个键被 zon 原样收下、无人过问,窗口拿的还是默认的 `quit`。1.19.1 起 runner 真的读它,并由 `scripts/manifest-check.mjs` 在两条流水线上守着:**清单里声明的每个键,runner 必须真的在读** |
| 侧栏 | **P** 开关(或顶栏 ☰ —— 标签行里原本还有一个 ✕,已撤掉:它和三个页签同高、同行、同对齐,却不是页签,而关闭本来就有两个不伪装成页签的入口)；**分「对局 / 设置 / 记录」三个标签页** —— 对局段放棋谱、复盘条、曲线与回顾、本局操作,设置段放难度/执子/棋钟/主题/语言/音效,记录段放统计/对局历史/成就;模式(人机/双人/教学/做题)常驻名条下方,切换模式自动回到对局段;**主题 木/夜/日/纸 —— 连棋盘一起换**(棋盘四角改为直角并补一道内描边:同心圆角要求「内角 = 外角 − 内边距」= 16 − 17 < 0,原本 6px 比同心更圆,看着是贴在框上而不是嵌进框里)(到 1.11 为止四套主题共用同一块 lichess 棕板,只有边框在变;现在各有一套格子色、选中色、上一手色与提示点色,四套下棋子描边对格子的对比实测 5.86–17.72:1,均高于非文本图形 3:1 的下限) · **界面语言 中文/English/日本語**（620 个界面键三语齐备；**教学课文、题库与开局名称/思路三语齐备**（日文自 1.21 起全覆盖，现为：课文 72 课 · 题名 168 · 开局名 162 · 开局思路 109）；实测英文模式下各视图可见中文串数为 0）· 音效开关 |

| **成就 / 统计** | 侧栏「成就」：15 枚徽章从教学/做题/对局进度自动解锁,**一经解锁永久保留**,未解锁的计数型徽章显示进度；「统计」按难度记录胜负和、分析过的对局记录**精准度**,并给出一句**「接下来做什么」**的建议(教学未完成 / 该升降难度 / 该去复习) |
| **对局回顾** | 「分析」跑完后给出双方精准度与平均失分、小失误/失误/严重失误分布、开局名,并标出**评分变化最大的一步**——点击直接跳到该步之后的局面 |
| **对局历史** | 侧栏「统计」下列出最近 5 局人机对局(胜负和 · 难度 · 执子 · 时间 · 回合数 · 已分析的精准度),「全部 N 局」打开完整列表(最多保留 500 局);**点一局即载入棋盘**,分析/回顾报告/导出 PGN/另存到存档槽对它原样可用,每行另有 PGN 按钮直接复制该局;**可按结果(胜/负/和)与执子(白/黑)筛选** —— 「我输过的黑棋」不必再靠翻;认输、协议和棋、判和、超时结束的对局会连**终局状态**一起复原,不会被交还给引擎接着下 |

## 规则引擎

局面合法性由 vendored [chess.js](https://github.com/jhlywa/chess.js) 0.13.4（BSD-2-Clause）判定——
不自研规则。`src/web/js/chess.js` 顶部注明了从 ESM 到经典脚本的机械转换（zero:// 方案下 WebView
只验证过经典脚本加载）。

chess.js 之上,`js/fide.js` 补齐它不做的比赛规则判定：三次重复与 50 回合是**可声明**和棋（art.
9.2/9.3）而非自动结束,五次重复 / 75 回合才自动判和（art. 9.6）；超时是否算输由「能否将杀」而非
子力数量决定（art. 6.9）。复盘分析对每个局面用的是**同一套判定**而不是 chess.js 的 `game_over()` ——
后者在三次重复和 50 回合就返回 true，照它记分会把还能继续的局面一律记 0，把局势曲线拉到轴上，
并且带偏其后每一步的失误分类与准确率。重复计数比较的是**可走着法**而不是 FEN —— FEN 只要有兵走两格就写上吃
过路兵格,哪怕没有兵能吃,直接比字符串会把同一个局面算成两个（`1.e4 e5 2.Nf3 Nf6 3.Ng1 Ng8
4.Nf3 Nf6 5.Ng1 Ng8` 就会漏判）,因此只有真正存在合法吃过路兵时才保留该权利。

## 对弈引擎

[Stockfish.js](https://github.com/nmrugg/stockfish.js) 18 lite-single（GPLv3，单线程 + lite NNUE，
约 7MB），vendored 于 `third_party/stockfish/`。zero:// 方案不能加载 worker 脚本也不能 fetch 打包
文件，因此构建时由 `scripts/gen-engine-src.mjs` 把 loader 文本与 wasm base64 生成为
`engine-src.js` 全局量，运行时 `engine.js` 用 Blob worker + `postMessage` 传 wasm 启动引擎——
全程零 URL 解析。难度用 UCI `UCI_LimitStrength/UCI_Elo`（1320–3190）限强，「极限」为满强度；
「新手」和「休闲」不靠 UCI 选项：Stockfish 的 `UCI_Elo` 下限是 1320，比真正的初学者高得多，
而实测 Skill Level 1 仍有约 27 ACPL（与入门档无异）。所以这两档改为**浅层 MultiPV 搜索 + 候选抽样**
（会主动取差着，但绝不放弃已算出的杀棋），靠 `worstBias` 调档：新手 0.2、休闲 0.15 且候选更少。

强度不用 ACPL 背书 —— ACPL 说不清「初学者赢不赢得了」。`scripts/test-novice.mjs` 直接对下：
一个只会「不一步送子」的随机机器人，32 盘对新手得分率 **56%**、对休闲 **27%**、对入门（1320）几乎为零。
（这三个数与下面各档的平均失分都来自 [`docs/measured.json`](docs/measured.json)，由
`node scripts/test-novice.mjs --record` / `test-strength.mjs --record` 写入；单测校验本文与
`engine.js` 的注释引用的是同一份数,不是各自记着的一份。1.25 之前正是各记各的：
README 记 56%/27%（32 盘），engine.js 注释记 66%/25% 且没写盘数。）
1.18 之前新手档 `worstBias` 是 0.6（六成的着法是十个候选里最差的那个），同一个机器人打出 **81%** ——
那不叫弱，叫自己送；而它上面一格就是 1320，没有中间地带。`scripts/test-strength.mjs` 另按满强度评估
量每档的平均失分。抽样走固定种子，但参照评估是按时间搜的，所以**它逐位复现不了**——
断言因此写成带容差的「档位之间不许实质倒挂」加各档绝对上下限，而不是两个噪声均值之比。

## 开发

前置条件（`package.sh` 只面向 macOS，其余脚本跨平台）：

| 需要 | 用来做什么 | 没有会怎样 |
|------|-----------|-----------|
| Node 22+ | 跑 `scripts/` 下的全部检查与代码生成 | 什么都跑不了 |
| `npm ci`（唯一依赖:esbuild） | 把 `src/web/js` 的 ES 模块打成 `js/bundle.js` | 页面加载不出来:index.html 只加载这一个脚本 |
| Zig 0.16.0 | 编译 `src/*.zig`（`package.sh` 从 `~/.native/toolchains/zig-0.16.0` 找） | 只能改前端，编译不了 |
| Native SDK CLI（`@native-sdk/cli`） | `native package` 打出 `.app` / `.exe` | 编译得出二进制，打不出安装包 |
| Playwright + Chromium / WebKit | 六个浏览器 E2E（两个引擎各跑一遍）| 各自打印「跳过」并通过；发布流水线设 `E2E_REQUIRED=1`，那里跳过即失败 |

- `node scripts/test-chess.mjs` —— 规则/课程/题库/开局/成就/纯函数模块（快,打包流程内置）

- `node scripts/test-board-e2e.mjs` —— 真下到将军与将死,四套主题各数一遍棋子（需 playwright + Chromium,没有就跳过）
- `node scripts/test-clock-e2e.mjs` —— **切走之后棋钟会不会空跑**（用假桥发 app:deactivate/activate,离开 6 秒后时钟必须一秒没掉。1.17 实测 8.4 秒后台掉 9 秒;第一版测试靠切标签页做背景,无头模式下页面仍报 visible,量了个寂寞还“通过”了。需 playwright + Chromium,没有就跳过）
- `node scripts/test-content-e2e.mjs` —— **课程与实战题在页面上是不是真的能用**（真点开每一节残局课、走错一步再走对一步、做完一道实战题;1.17 靠它发现课文里的 `**重点**` 从 1.4 起一直是把星号原样印出来的。需 playwright + Chromium,没有就跳过）
- `node scripts/test-persist-e2e.mjs
node scripts/test-review-e2e.mjs` —— **重开之后还记得什么**（真从「载入 FEN」摆一个残局、不走子就重开,棋盘必须还站在那个局面上;1.21.1 之前这样会静默丢局面 —— 零着的存档只有 `[FEN]` 头,`load_pgn` 不收,启动路径当成「没有存档」,接着用初始局面把它覆盖掉。需 playwright + Chromium,没有就跳过）
- `node scripts/test-layout-e2e.mjs` —— **侧栏的版式**（从真实盒模型上量:换行分段控件里每个按钮一样宽（`flex: 1 1 30%` 会让最后一行自己分掉整行,四个按钮里的第四个就长成整块主按钮）、四个模式页签在三种语言下都是一行高不裁字、六个难度标签互不重复、标签行里只有页签、没有陪练的教学课不画对手卡。这些是只有排完版的页面能回答的问题,也正是凭印象最容易答错的那一类。需 playwright,没有就跳过）
