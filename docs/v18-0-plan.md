# 18.0 · 按你的水平练

写于 17.0.0 发布之后（2026-11-04）。规矩照旧：每条写**依据**、**做什么**、**验收**，发布前补**落地记录**。

**结论**：
- 15.0、16.0、17.0 连着三版做的是减法和做工：少几个按钮、零件统一、棋子换成 Merida、棋盘回到纯色。界面现在干净了。
- 应用里最有分量、却一直没用到训练上的，是 13.0 加进来的 **Maia**：五个「像人一样下棋」的模型，1100 到 1900 每 200 分一个。
- 它现在只做两件事：陪你下棋，在复盘里说「人会怎么走」。训练还是只认「对 / 错」：谜题只按难度出，开局书的对手只走书上写的那一步。
- 「按你的水平练」在 14.0 就量过可行性，之后连推了三版。
- 18.0 推荐把它做成这一版的主线：**C 按你的水平练** + **E 工程**。不改界面风格。

---

## 依据

1. **14.0 计划附录 A 量过的数**。模型、题库没换过，这些数现在仍然成立：
   - **从现有谜题里挑「大家都会错」的题**：4 万道 Lichess 谜题，每个分段抽 400 道。看该分段的 Maia 最可能走的第一步：不是正解、且概率 ≥ 35% 的比例是 1100 段 21%、1300 段 26%、1500 段 39%、1700 段 39%、1900 段 45%。每段合格的都在 800 道以上。
   - **从对局里挖同样的局面**：只有 1.5–3% 合格，太少，不做这条路。
   - **Maia 每次前向**：27–65 ms。一本 100 条线的开局书全算一遍要 10–30 秒，所以要在后台算、算完存下来。
   - **用温度让 Maia 1100 下得更弱**：温度 3 时约 1003 分，和真人着法的吻合率 23%，≥ 300 cp 的大错率 20.5%。附录里同时记着「稳健」那一档：吻合率 15%、大错率 18%。
2. **现在的训练怎么出题**：
   - 「为你出一题」取离你等级分最近、没做过的题。
   - 错题进间隔复习：1 → 3 → 7 → 21 天。
   - 题面只说「白先」「找出最好的一步」，做完只说对错。
   - 你在这道题上会犯的错，和同水平的人常犯的错有没有关系，应用不知道，也不告诉你。
3. **开局书**：
   - 背书时一次练一条线，对手走的就是这条线上写的那一步（`repertoire.js` 把每条从根到叶的路径变成一条线）。
   - 真实对局里，对手走的往往是书上没准备、但同水平的人最常走的那一步。
4. **开局浏览器**：
   - 现在给的是内置的大师着法树（Lichess 对局库）。
   - 1300 分的人在这里常走什么，大师树答不了，Maia 答得了。
5. **README 的「路线」一节过期了**：
   - 它还指着 13.0 的计划。
   - 「接下来」第一条是 15.0 已经做完的 Node 26。
   - 西班牙语、Chess960、研究 / 笔记本写在「以后」里，没有说清现在的打算。

**局限**：
- Maia 只有 1100–1900 五个分段。低于 1100 或高于 1900 的人，C1–C3 只能取最近的那一段，说明里要讲清楚。
- 「同水平的人会怎么走」是模型的估计，不是真人统计。界面上的叫法要诚实（第 8 节第 3 条）。
- 没有真机反馈。16.0、17.0 请你看的几件事还没有回音。

**推荐 C1 + C2 + C3 + E。** 理由：
- **都建立在已有的东西上**：Maia 已经打包，题库、开局书、浏览器都在，不需要新的数据来源或许可证。
- **都回答同一个问题：「我这个水平的人会在哪里出错」**。这是现在的训练完全没碰的一块，也是 Chess.com、Lichess 都还做得很浅的一块。
- C4 能让最弱的几档更像人，但量出来的差别不大（吻合率 23% 对「稳健」一档的 15%），还要逐档重测，放到可选。
- S、V、ES 各自是一整块新功能，用的人比 C 少，留在路线图上。

## 1 · C1 「大家都会错」的题

**依据**：依据第 1、2 条。

**做什么**：
- **离线预算**（`scripts/` 新脚本，像 `import-puzzles.mjs` 一样只在更新题库时跑）：
  - 对 1100–1900 五个分段的每道 Lichess 题，用该分段的 Maia 算第一步。
  - 记下 Maia 最可能的那一步，以及它和正解各自的概率。
  - 每道题只多两个字段，写进现有的分段分块，不进首屏包。
- **新的一类题「大家都会错」**：
  - 放在谜题的六类旁边，按你的等级分取最近的分段。
  - 出题条件：该分段 Maia 最可能的第一步不是正解，且概率 ≥ 35%。
- **做完的结果条**：多一句「同水平的人约 39% 会走 Nxe5」。
  - 答对时这是表扬。
  - 答错且正好走了那一步时，告诉你这是个常见的坑，并把这道题标成「大家都会错」进复习。
- **今天页**：「接下来」里可以排一组 5 道「大家都会错」，排在到期复习之后。

**验收**：
- 五个分段每段合格的题 ≥ 800 道，抽查 100 道：Maia 最可能的那一步确实不是正解。
- 预算脚本可重复：同一题库、同一参数，输出逐字节相同。
- 分段分块的增长写进计划，首屏包不变。
- e2e：新一类能出题；做完后的那句话里，百分比与预算的数据一致。

## 2 · C2 开局书的对手按人来应

**依据**：依据第 3 条。

**做什么**：
- **背开局书时，对手的每一步换成你这个分段的人最常走的那一步**，按你的对局等级分取分段。只在你书上那一方的回合之外起作用。
  - 那一步在你的书上：照常往下背。
  - 那一步你的书没准备：停下来，告诉你「同水平的人约 X% 走这一步，你的书里还没有」，并给「加进开局书」。
- **后台计算**：每条线只算对手的回合，结果按局面存进开局书的库，书不变就不重算。100 条线的书第一次约 10–30 秒，期间照常按书上的应着背。
- **设置**：开局书页加一个分段控件「对手：按书走 / 按同水平的人走」，默认后者。

**验收**：
- 一本 100 条线的书：首次计算不阻塞界面（布局 e2e 量长任务 < 200 ms），再次打开不重算。
- 书没准备的应着会停下来给出那句话，点「加进开局书」后这一步进书。
- 「按书走」与 17.0 行为完全相同（现有开局书 e2e 照旧全过）。

## 3 · C3 开局浏览器「同水平的人」

**依据**：依据第 4 条。

**做什么**：
- 开局浏览器在大师着法下面多一栏「同水平的人」：你这个分段的 Maia 给出的前三步和各自的概率。
- 一句说明写清这是「同水平棋手的模型估计」。
- 只在浏览器打开、局面变化时算一次，用现有的 Maia 加载与缓存。

**验收**：
- 打开浏览器后 ≤ 300 ms 出现这一栏（Maia 已加载时），不挡住大师着法的显示。
- 三种语言的说明不截断；三步的概率加起来 ≤ 100%。

## 4 · C4 弱档对手换成 Maia（可选）

- 1100 以下的几档改用 Maia 1100 加温度：温度 3 约 1003 分，更低的档位用更高的温度，逐档实测。
- 人感测试照 13.0 的方法重做；不比现有的抽差 Stockfish 更像人就不换。
