# 10.0 · 从「会用」到「会进步」：把训练接成一个闭环

写于 9.0.0 发布当天（2026-10-10）。规矩照旧：每条写**依据**、**做什么**、**验收**，发布前补**落地记录**。

9.0 把已有的功能收成了一个产品：五个去处、一处设置、一套设计语言。10.0 要回答的是下一个问题——**一个人每天打开它，会不会真的越下越好**。现在各块都在（复盘、错题、诊断、谜题、开局书、课程），但彼此不通：复盘找出的失误不会回来找你，诊断只能看不能练，开局书要先自己找 PGN。这一版主要把它们接起来；另外加第一门新语言，补齐工程上的欠账。

## 0 · 结论先行

### 9.0 之后，最大的缺口是「不通」

| 任务 | 现在 | 断在哪里 |
|---|---|---|
| 零基础第一次打开 | 选「先看看棋盘」就落在索尔 1700「中级」；新对局对话框露出的 8 张卡最低 1320 | 没有定级；默认档对新手太强；首启说明还写着「难度可随时在侧栏调整」（9.0 已没有侧栏设置） |
| 复盘网上下的一局 | 设置·数据打开联网 → 填用户名 → 同步 → 在库里找 → 打开 → 分析，6–8 步；或去「更多」里找「粘贴 PGN」 | 没有「分析一局」这个入口；没有独立的分析棋盘 |
| 从自己的失误里练 | 复盘里「从错误中学」能串成一组；谜题有「我的错题」类 | 没有错题时这一类干脆不显示；失误不会自己回来找你（没进间隔复习）；今天页不提 |
| 知道自己弱在哪 | 「我的」有三项跨局指标，棋谱库攒够 20 局能「看诊断」 | 只读；看完不知道练什么 |
| 练开局 | 开局书要先导入一份带变着的 PGN | 门槛在第一步；内置 119 条开局思路用不上 |

### 版本号：10.0

- **理由**：训练这条线从「各自一块」变成一个闭环——今天页每天给出「接下来练什么」，背后是定级、错题复习、弱项、开局书四个来源；外加第一门新界面语言（西班牙语）。用户看得出不一样。
- **存档**：沿用 9.0 的 SCHEMA 3，不再重置；10.0 起新增的数据（定级结果、错题复习队列、本周重点）在 SCHEMA 3 里加字段，读 9.0 的档案。§8 第 2 条请你定是否继续「不背历史」。

### 10.0 的三个主题 + 两件事

| | 主题 | 一句话 |
|---|---|---|
| **T** | 训练闭环 | 定级 → 每天的「接下来」→ 练 → 复盘 → 失误回到复习；诊断变成本周重点 |
| **A** | 分析一局 | 粘贴 / 拖入 / 链接，一步到分析；独立的分析棋盘；教练用平白的话讲 |

## 1 · T：训练闭环

### T1 首启定级与新手默认档【M】

- **依据**：首启只问两个选项（`app.js` `runOnboarding`）；「先看看棋盘」不改难度，落在索尔 1700；Duolingo Chess 先问熟悉程度、零基础从走子学起。§6（9.0）延后的「首启定级问卷」。
- **做什么**：三档自评（没下过 / 会走子 / 常下）+ 后两档各 5–8 道自适应小题（复用谜题题库与定级算法），可选「导入 Lichess / Chess.com 用户名」（走现有同步，联网仍需在设置里允许）。结果写谜题等级分初值、默认对手档、今天页第一件事（零基础 → 第 1 课）。默认档改成「休闲」；改掉 `ob.knowSub` 那句。
- **验收**：首启到第一件事 ≤ 3 次点击；三档各落在约定的起点（e2e）；跳过问卷 = 现在的行为但默认档是休闲。

### T2 自己的失误进间隔复习【S】

- **依据**：失误串成「从错误中学」只在复盘当场；「我的错题」没题时不显示（谜题网格空一格）；Lichess「Learn from your mistakes」与 Aimchess Retry Mistakes 是两家最受欢迎的功能。
- **做什么**：每次分析完一局，你这一方的 ? / ?? 自动进「我的错题」并排进间隔复习（与谜题复习同一套 SRS）；「我的错题」始终显示，空时写清楚它是什么、怎么攒；今天页把到期的错题排进「接下来」（「昨天那局第 23 步」）。
- **验收**：分析一局 → 错题数加上你的失误数；到期后今天页出现；做对排到下一个间隔。

### T3 诊断变成「本周重点」【M】

- **依据**：「我的」的三项跨局指标（化优为胜、逆境求生、时间紧）与棋谱库诊断都是只读的；Aimchess 按六个维度给训练计划。
- **做什么**：每周一次（或攒够 N 局），把诊断写成今天页的「本周重点」：两三项，每项一键开始（「残局：车残局 5 个」「战术：牵制 10 题」「开局：你执黑的西西里，第 6 步之后」）。数据不够时说「再下 N 局」。
- **验收**：有 ≥ 20 局时出现本周重点；每一项点进去就是对应的训练；做完划掉。

### T4 开局训练零门槛【M】

- **依据**：开局书要先导入带变着的 PGN；Chessable 的 MoveTrainer 是逐着间隔复习；内置 119 条开局思路（三语）只用于讲解。
- **做什么**：「我的开局书」一键「从内置开局生成」（选执白 / 执黑、选一套体系）；复盘时开局阶段偏离开局书的着法提示「加入开局书」；开局书的复习逐着排期（已有的 `rep` 逻辑接 SRS）。
- **验收**：新档案三次点击开始练开局；复盘里出现「加入开局书」；逐着复习按间隔出现。

### T5 今天页成为每天的入口【S】

- **依据**：今天页主卡已经是「接下来一件事」，来源只有课程 / 谜题 / 对局；评审：主卡里「学一节新课 / 来一盘」像单选框，「继续」三门没开始也写 0/7。
- **做什么**：「接下来」按优先级取：到期错题 → 本周重点 → 开局书复习 → 课程 → 一盘；最多三条，每条一句话加一个按钮；空等级分卡、未开始的「继续」改成邀请，而不是 0 和横线。
- **验收**：同一份档案的「接下来」可解释（每条写来源）；新档案只有一条（第 1 课或定级）。

## 2 · A：分析一局

### A1「分析一局」入口与分析棋盘【S–M】

- **依据**：复盘网上一局 6–8 步；「粘贴 PGN / 编辑局面」藏在对局侧栏的「更多」里；Lichess 可按 URL / PGN 直接开分析。
- **做什么**：棋谱页和今天页一个「分析一局」：粘贴 PGN、拖入文件、粘贴 Lichess / Chess.com 对局链接（要联网，走设置里的允许开关）→ 直接进复盘。独立的「分析棋盘」：摆局面、引擎多线、走变化，不算一局对局。
- **验收**：从启动到看到一局的复盘 ≤ 3 步（PGN）；分析棋盘不进战绩。

### A2 教练用平白的话讲【M】

- **依据**：Chess.com Game Review 改版把 Coach 放在最前面，按关键时刻讲、可重试，并有「错过的机会」一类；这里 `explain.js` 已能用事实写出一句原因，但默认收着；9.0 留下「悬停失误点时棋盘上的迷你箭头」。
- **做什么**：关键时刻卡上「为什么」默认展开；在棋盘上画出反驳那一手的箭头；补「错过的机会」（对手送了、你没拿）；总结句把将杀算进胜率变化（评审：学者将杀那局曲线跳到 100%，总结却说没有明显下滑——先查是截图桩的问题还是 `summaryText` 的问题）。
- **验收**：三种关键时刻（失误、错过、妙着）在 e2e 的固定局里各出现一次；箭头只在关键时刻画。

### A3 ⌘K 命令面板【S–M】

- **依据**：9.0 §6 延后；「更多」里藏着粘贴 PGN、编辑局面、导出、存档槽。
- **做什么**：⌘K / Ctrl+K：搜索并跳到某一课、某个残局、某个谜题主题、库里某局，以及动作（粘贴 PGN、分析一局、编辑局面、新对局、设置的某一类）；键盘到底；三语都可搜。
- **验收**：九个核心任务里至少五个可以从 ⌘K 一步开始；面板不进主包（分块）。

## 3 · L：西班牙语【M + 翻译 L】

- **依据**：F4（8.2）已把拼句改成整句模板、字典按语言分块、复数走 `Intl.PluralRules`；`LANG_IDS` 一行；原生菜单有自己的表（`menus.zig`）。打包的 Inter Latin 子集已覆盖西语，不需要新字体。

### 不做的技术事（这次评估后的结论）

- **换引擎形态**：多线程要 SharedArrayBuffer，SDK 0.10.1 两个平台的 `zero://` 都不发 COOP/COEP 头（macOS 回的是不带头的 `NSURLResponse`）；原生 Stockfish 进程要每平台一个二进制、签名、约 100 MB 的大网、重新标定 5,505 局的天梯。**不做**；向上游提「`zero://` 可配响应头」，落地后花一天验证 `crossOriginIsolated`。
- **SQLite**：IndexedDB 1 万局冷启 230 ms 出列表、位置索引 526 ms，原生分片镜像已防 WebView 清数据；SDK 的 SQLite 是 model-core API，不通 WebView 页面。**不做**，除非 IndexedDB 在某个平台出事。
- **Chess960**：内嵌的 chess.js 0.13.4 与最新 1.4.0 都不支持；改动横跨约 13 个用到规则的模块与所有开局功能。**10.x 以后**，作为限定模式（人机 + 库里能看）。
- **研究 / 笔记本（Lichess Study 那样）**：L，排在最后，10.0 不做。
- **macOS 签名、公证、自动更新；Windows 安装包与签名**：SDK 0.10.1 已有 notarytool、DMG 装订与签名更新器，工程量小，卡在证书。有证书就做（§8 第 6 条）。
