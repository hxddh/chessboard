# 真机走查清单

自动化能覆盖的，都已经在 `checks.yml` 和发布门禁里跑了：规则、纯函数、源码守卫、六个浏览器 E2E（Chromium 与 WebKit 两个引擎，含侧栏版式量测与 2.0 新增的「任一时刻可见禁用控件数为 0」「题型 × 难度每个组合非空」）、Stockfish 的开局与战术检查、`zig build test`。

**这份清单是剩下的那一半 —— 没有任何自动化碰得到的部分。**

为什么值得照着念一遍：这一层历史上出过的问题，没有一个是小问题。

| 版本 | 问题 | 潜伏了多久 |
|---|---|---|
| 1.10–1.21.0 | 原生菜单栏其实是画上去的，⌘N / ⌘Z 一次都没触发过 | 十一个版本 |
| 1.18–1.19.0 | macOS 关窗直接退出（`close_policy` 声明了没人读） | 两个版本 |
| ≤1.21.1 | 大于 256 KiB 的 PGN 被静默截断成前 256 KiB | 未知 |
| ≤1.21.1 | Windows 路径的每个 `\` 都被送成 `\\` | 未知 |

它们都不会让任何测试变红，因为测试根本够不到那一层。

**怎么用**：照顺序做，每条对照「应该看到」。任何一条对不上就停下来记录 —— 写清楚你做了什么、看到了什么、期望是什么。不必自己判断严重程度。

标注说明：**[M]** 仅 macOS · **[W]** 仅 Windows · 无标注 = 两个平台都要做。

---

## A. 安装与首次启动

| # | 做什么 | 应该看到 | 坏了会是什么样 |
|---|---|---|---|
| A1 | **[M]** 下载 zip、解压、把 `Chessboard.app` 拖进「应用程序」，双击 | 首次会被 Gatekeeper 拦；右键「打开」后正常启动 | 提示「已损坏，应移到废纸篓」——那是签名问题，不是 Gatekeeper 的常规拦截 |
| A2 | **[W]** 解压后运行 `Chessboard/chessboard.exe` | 窗口出现，棋盘可见 | 白屏或报缺 WebView2 运行时 |
| A3 | 全新用户第一次打开 | 走一遍引导；界面语言跟随系统（中文系统 → 中文） | 引导不出现，或语言固定成中文 |
| A4 | 关掉再开 | 回到关掉时的局面 | 回到初始局面 = 存档没恢复 |

## B. 原生菜单与快捷键 —— 曾经整整十一个版本是假的

| # | 做什么 | 应该看到 |
|---|---|---|
| B1 | 看菜单栏，逐个展开每个菜单 | 菜单项与 `app.zon` 声明一致，不是系统默认那一条 |
| B2 | 按 **⌘N / Ctrl+N**（新局） | 弹出确认（有棋谱时），确认后开新局 |
| B3 | 按 **⌘Z / Ctrl+Z**（悔棋） | 退回一手 |
| B4 | 按 **⌘⇧H / Ctrl+Shift+H**（提示） | 棋盘上出现提示箭头 |
| B5 | 从菜单点上面每一项 | 和快捷键效果一致 |

> B2–B4 是 1.18 那次「把提示键从 ⌘H 改成 ⌘⇧H」真正想修的东西。当时那条线根本没通电。

## C. 文件桥 —— 上一轮外部审计两条 bug 都在这里

| # | 做什么 | 应该看到 |
|---|---|---|
| C1 | 「导出」保存 PGN，选一个普通路径 | 保存成功，文件管理器把它显示出来 |
| C2 | **保存到带空格和中文的路径**，例如 `~/我的 棋谱/` | 同样成功，文件真的在那个目录里 |
| C3 | **[W]** 保存到 `C:\Users\<你>\Desktop\` | 成功。**曾经这里每个 `\` 都会变成 `\\`** |
| C4 | 「打开文件」导入一个普通 PGN | 局面载入 |
| C5 | **导入一个大于 256 KiB 的多局 PGN** | 提示「文件超过 256 KB，读不进来」。**不允许**只导入前面一部分而不吭声 |
| C6 | 导入一个正好几十 KB 的多局棋谱库 | 弹出选局窗口，列出全部对局，选哪局进哪局 |
| C7 | 把 `.pgn` 拖进窗口 | 同样导入 |
| C8 | **导出复盘图**（先分析一局）| 保存成 `.png`，用看图软件打开是完整的复盘图 —— 曲线、失误点、双方数据都在。**1.23 新增，这条路径从未在真机上按过** |
| C9 | 做完 C1/C4 后看 Dock 右键菜单 **[M]** / 跳转列表 **[W]** | 刚才的 PGN 出现在最近文件里 |
| C10 | 设置里「清除存档」 | 最近文件列表**一并清空** |

## F. 这一版的新东西（2.0：界面重制）

> 2.0 是 P-1 → P6 七个阶段的整改，界面被重新排过一次。能写成断言的都已经写了
> —— 可见禁用控件数、危险动作的位置、四主题 × 三语言的对比度与截断、每条动画
> 对应哪个问题、题型 × 难度组合非空。**这里只留自动化按定义够不到的那类：
> 「这样看起来对不对、用起来顺不顺」，以及真机字体与真机音频下才成立的事。**
>
> 1.25 那一组（难度标签近义词 / 分段控件等宽 / 页签不折行 / 教学不画空对手卡 /
> 「演示」不置灰 / 标签行没有 ✕）已全部由 `test-layout-e2e.mjs` 接管，不再念。

| # | 做什么 | 应该看到 |
|---|---|---|
| F1 | 盯着棋盘上方那条栏，走十来步棋 | **它不该把你的视线从棋盘上拉走**。2.1 之前那里站着九个控件（四个模式 + 状态 + 提示/悔棋/翻转/新局 + ☰），其中视觉最重的是渐变实心的「新局」——对弈中最不该按的那个。现在只剩状态、悔棋、提示、☰，且四者同高同基线。自动化能量高度与位置，量不了「它是不是在抢注意力」 |
| F2 | 开局前（0 手）、下到一半、下完各看一遍整个面板 | **看不到任何灰着的控件**。自动化查了前两种时态，第三种（已结束）与「危险动作确认」这类例外只有人分得清 |
| F3 | 把侧栏收起来（P 或顶栏 ☰），看棋盘下方 | 一条「脊」：轮谁走 · 棋钟 · 上一手 · 子力差。收起面板不该把整局棋一起收走。**它该在棋盘下面，不该压在棋盘上** —— 2.1.2 之前它盖住了 a–h 那行字母和第 1 横线的最后几像素 |
| F3b | 收起侧栏后，把窗口从最大一路拖到最小（520×520） | 脊始终在棋盘下方那条空带里，不进棋盘、不出窗口；棋盘不会因为脊出现或消失而改变大小 |
| F4 | 设置页刚打开时 | 每段先给**一行摘要**（当前难度/执子/钟/主题），控件折起来。展开一段，看它是不是真的展开 |
| F5 | 「认输」，把音量开着 | **不是胜利号角**。2.0 之前认输、被将死、超时判负三处都播的是赢棋那段。这一条现在由 `test-audio-e2e.mjs` 在浏览器里量（人机认输、双人认输、将死、被将死、判和各一条），留在这里是因为机器只认得频率，认不出音量是不是压过了棋子声 |
| F5b | 音量开着，点起一枚棋子，再点一个它去不了的格子 | **两声是不同的**：点起来是那一下最轻的「拿起」，点错地方才是闷响的「不行」。2.1.5 之前这两声是反的 —— 点起棋子播的是拒绝那一声，而真的被拒绝时一声不响 |
| F6 | 分析一局，导出复盘图，**把 PNG 贴进一份白底文档里**（Word / 备忘录都行） | 字看得清。这条自动化查不了 —— 它能查画布像素，查不了「贴到别处还读不读得出来」 |
| F6b | **同一张图，对着屏幕上的面板逐个数字核一遍**：白方那一列的精准度、平均失分、`?! · ? · ??` 三个数，和面板里「白方」下的三行是不是同一批数；关键一步说的是不是同一个人走的 | 完全一致。**2.1.2 之前这里两列的标题是反的** —— 装着白方数字的那一列写着「黑方」，关键一步也报成了对手。面板从来是对的，图从来是错的，而没有任何测试够得到画布上的字 |
| F6c | 切到 English 和 日本語 各导出一次 | 三种语言下两列都不越界、标签不压到数字上。数字列右对齐、标签列左对齐 |
| F6d | 用键盘下一整局：Tab 到棋盘，方向键移光标，回车选中与落子 | 光标看得见（棋盘上那个双描边的方框），而且**看得出它落在哪一格**。自动化量得了光标画在哪、读屏那一行说了什么，量不了「在这四套主题上它是不是都还看得清」 |
| F7 | 拿起一个棋子拖着走 | 它不是被放大 12% 的位图（边缘不该发虚）；静止的子在格子上有接触阴影 |
| F8 | 切到 日本語，看课文与题面里的汉字 | 是日文字形。2.0 之前字体栈里三个 CJK 字体全是简中（含 Hiragino Sans GB，GB = 国标），日文汉字由简中字体供给，**字形肉眼可辨地错**。这条只有真机字体答得了 |
| F9 | 教学 → 「捉双」那一课学完 | 出现「接着练 N 题」；按下去落在同一母题的题目上，而不是题库第一题 |
| F10 | 做题 → 逐个点「吃子 / 实战 / 防守 / 开局」四类的三个难度档 | 每一档都有题。杀王三类**不显示难度这一行**（不是显示了按不动） |
| F11 | 教学 → 任一残局 drill，故意下输 | 失败提示讲的是**技术**（「王要顶上去」「先逼到边上」），不是只报「被将死了 —— 重来」 |

## 记录格式

发现对不上的地方，按这个格式写，不用加判断：

```
条目: C5
做了: 导入一个 1.2 MB 的多局 PGN
看到: 只进来了前 40 局,没有任何提示
期望: 提示「文件超过 256 KB，读不进来」
平台: macOS 15.1 / Chessboard 1.25.0
```

**一条都没对不上，也请说一声** —— 这份清单第一次跑完本身就是一个结果：它把「没人验过」变成「验过且是好的」。
