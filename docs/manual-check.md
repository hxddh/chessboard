# 真机走查清单

自动化能覆盖的，都已经在 `checks.yml` 和发布门禁里跑了：规则、纯函数、源码守卫、五个浏览器 E2E（Chromium 与 WebKit 两个引擎）、Stockfish 的开局与战术检查、`zig build test`。

**这份清单是剩下的那一半 —— 没有任何自动化碰得到的部分。**

为什么值得照着念一遍：这一层历史上出过的问题，没有一个是小问题。

| 版本 | 问题 | 潜伏了多久 |
|---|---|---|
| 1.10–1.21.0 | 原生菜单栏其实是画上去的，⌘N / ⌘Z 一次都没触发过 | 十一个版本 |
| 1.18–1.19.0 | macOS 关窗直接退出（`close_policy` 声明了没人读） | 两个版本 |
| ≤1.21.1 | 大于 256 KiB 的 PGN 被静默截断成前 256 KiB | 未知 |
| ≤1.21.1 | Windows 路径的每个 `\` 都被送成 `\\` | 未知 |

它们都不会让任何测试变红，因为测试根本够不到那一层。

**怎么用**：照顺序做，每条对照「应该看到」。任何一条对不上就停下来记录 —— 写清楚你做了什么、看到了什么、期望是什么。不必自己判断严重程度。

标注说明：**[M]** 仅 macOS · **[W]** 仅 Windows · 无标注 = 两个平台都要做。

---

## A. 安装与首次启动

| # | 做什么 | 应该看到 | 坏了会是什么样 |
|---|---|---|---|
| A1 | **[M]** 下载 zip、解压、把 `Chessboard.app` 拖进「应用程序」，双击 | 首次会被 Gatekeeper 拦；右键「打开」后正常启动 | 提示「已损坏，应移到废纸篓」——那是签名问题，不是 Gatekeeper 的常规拦截 |
| A2 | **[W]** 解压后运行 `Chessboard/chessboard.exe` | 窗口出现，棋盘可见 | 白屏或报缺 WebView2 运行时 |
| A3 | 全新用户第一次打开 | 走一遍引导；界面语言跟随系统（中文系统 → 中文） | 引导不出现，或语言固定成中文 |
| A4 | 关掉再开 | 回到关掉时的局面 | 回到初始局面 = 存档没恢复 |

## B. 原生菜单与快捷键 —— 曾经整整十一个版本是假的

| # | 做什么 | 应该看到 |
|---|---|---|
| B1 | 看菜单栏，逐个展开每个菜单 | 菜单项与 `app.zon` 声明一致，不是系统默认那一条 |
| B2 | 按 **⌘N / Ctrl+N**（新局） | 弹出确认（有棋谱时），确认后开新局 |
| B3 | 按 **⌘Z / Ctrl+Z**（悔棋） | 退回一手 |
| B4 | 按 **⌘⇧H / Ctrl+Shift+H**（提示） | 棋盘上出现提示箭头 |
| B5 | 从菜单点上面每一项 | 和快捷键效果一致 |

> B2–B4 是 1.18 那次「把提示键从 ⌘H 改成 ⌘⇧H」真正想修的东西。当时那条线根本没通电。

## C. 文件桥 —— 上一轮外部审计两条 bug 都在这里

| # | 做什么 | 应该看到 |
|---|---|---|
| C1 | 「导出」保存 PGN，选一个普通路径 | 保存成功，文件管理器把它显示出来 |
| C2 | **保存到带空格和中文的路径**，例如 `~/我的 棋谱/` | 同样成功，文件真的在那个目录里 |
| C3 | **[W]** 保存到 `C:\Users\<你>\Desktop\` | 成功。**曾经这里每个 `\` 都会变成 `\\`** |
| C4 | 「打开文件」导入一个普通 PGN | 局面载入 |
| C5 | **导入一个大于 256 KiB 的多局 PGN** | 提示「文件超过 256 KB，读不进来」。**不允许**只导入前面一部分而不吭声 |
| C6 | 导入一个正好几十 KB 的多局棋谱库 | 弹出选局窗口，列出全部对局，选哪局进哪局 |
| C7 | 把 `.pgn` 拖进窗口 | 同样导入 |
| C8 | **导出复盘图**（先分析一局）| 保存成 `.png`，用看图软件打开是完整的复盘图 —— 曲线、失误点、双方数据都在。**1.23 新增，这条路径从未在真机上按过** |
| C9 | 做完 C1/C4 后看 Dock 右键菜单 **[M]** / 跳转列表 **[W]** | 刚才的 PGN 出现在最近文件里 |
| C10 | 设置里「清除存档」 | 最近文件列表**一并清空** |

## D. 窗口行为

| # | 做什么 | 应该看到 |
|---|---|---|
| D1 | **[M]** 点窗口左上红叉 | 窗口收起，**应用还在**，Dock 图标还在 |
| D2 | **[M]** 点 Dock 图标 | 窗口回来，局面原样 |
| D3 | **[M]** 按 ⌘Q | 这才真正退出 |
| D4 | **[W]** 点关闭 | 直接退出（Windows 就该是这样） |
| D5 | 把窗口尽量拖小 | 缩到某个尺寸就不再变小（`min_width`/`min_height` = 520），布局不塌 |
| D6 | 最大化 / 全屏 | 棋盘跟着放大且不糊（高分屏尤其要看） |

> D1–D3 是 1.18 和 1.19 连续两个版本失效的行为。

## E. 引擎

| # | 做什么 | 应该看到 |
|---|---|---|
| E1 | 开一局人机，等它走第一步 | 几秒内落子，界面不卡 |

## 记录格式

发现对不上的地方，按这个格式写，不用加判断：

```
条目: C5
做了: 导入一个 1.2 MB 的多局 PGN
看到: 只进来了前 40 局,没有任何提示
期望: 提示「文件超过 256 KB，读不进来」
平台: macOS 15.1 / Chessboard 1.24.0
```

**一条都没对不上，也请说一声** —— 这份清单第一次跑完本身就是一个结果：它把「没人验过」变成「验过且是好的」。
