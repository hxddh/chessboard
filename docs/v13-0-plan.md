# 13.0 · 对面坐着的像一个人

写于 12.0.0 发布之后（2026-10-16）。规矩照旧：每条写**依据**、**做什么**、**验收**，发布前补**落地记录**。

**已定（2026-10-16）**：按建议——做 H + I + E；带 5 个模型（1100、1300、1500、1700、1900）；直接替换阶梯里 1100–1900 的 7 档（名字、头像不变）；「人会怎么走」默认开。S、V 不做。

10.1、11.0、12.0 三个大版本都在打磨同一批东西：字、表面、构图、手感、声音、外壳。再磨下去，收益越来越小。这份计划回到「这个应用拿来干什么」：**一个人学棋、练棋、和电脑下棋**。三件事里，「和电脑下棋」是做得最弱的一件——对手是一台被故意弄笨的 Stockfish，不是一个人。

---

## 依据

1. **对手怎么变弱的**（`src/web/js/engine.js` 开头的注释，数字来自 `docs/measured.json`）：
   - UCI_Elo 最低只到 1320，Skill Level 1 也有约 27 ACPL，还是一个稳健的俱乐部棋手。
   - 所以低档是「先算出几个候选，再按概率故意挑差的」：`beginner` 有 14% 的着法是 ≥ 300 cp 的大错，但中位损失只有 46。
   - 这样弱下来的方式不像人：人丢子是有模式的（没看见的捉双、背后的斜线、底线），而这个对手的错是随机抽出来的。它会在完全平静的局面里白送一个车，下一步又走出引擎才找得到的好棋。
2. **路线图里挂了三版的「换引擎形态」**（README「路线」）。
3. **Maia**（CSSLab，多伦多大学 / 康奈尔 / 微软研究院，KDD 2020）：用 Lichess 上各个等级分段的真人对局训练的神经网络，目标是「预测这个水平的人会走哪一步」，不是「找最好的一步」。
   - 许可证：**GPL-3.0**，和本应用相同（已核对仓库 `LICENSE`）。
   - 九个模型 1100–1900，每个 1.26–1.31 MB（gz），解压 1.7 MB，lc0 的 protobuf 格式，6 个残差块 × 64 通道。已从 `raw.githubusercontent.com` 实际下载到 1100、1500、1900 三个。
   - 只用策略头、不搜索：一次前向约 3,000 万次乘加，纯 JS 在 worker 里估计 30–60 ms 一步（实现时实测）。
4. **12.0 的真机验收还没回来**（Mac 外壳、触感、Windows 标题栏、声音）。

**局限**：Maia 论文报告的「与真人着法吻合率」约 50%（同水平），这里要用自己的数据复测；它在残局和时间压力下不如在中局像人。

## 1 · H 像人的对手

**做什么**：

- **引擎层**：新增 `human-engine.js`，在 worker 里：
  - 读 lc0 的 protobuf 权重（自己写一个最小的 protobuf 解码，不加依赖）；
  - 把局面编码成 112 个平面（含 8 步历史，就是对局本身）；
  - 前向计算，从 1858 个策略输出里取合法着法；
  - 按温度抽样（同一局面不总走同一步，但不会抽到概率极低的着法）。
- **模型**：随应用带 **5 个**：1100、1300、1500、1700、1900，共约 6.4 MB gz。按需加载，不进首屏包。
- **阶梯**：
  - 21 档对手里，等级分落在 1100–1900 的那 **7 档**换成 Maia：solid 1208、easy 1320、easyplus 1420、normalminus 1542、normal 1700、normalplus 1797、hardminus 1876（`docs/measured.json` 的 `ladder.rating`）。档位、名字、肖像、开场白不变；风格（贪吃子、重原则、爱进攻）在 Maia 的概率上加权实现。
  - 注意：这些分数是应用自己阶梯上量出来的，不等于 Lichess 的分。哪个 Maia 模型配哪一档，要用对局重新量，不能按数字直接对。
  - 1100 以下仍用现在的「故意抽差的」Stockfish，1900 以上仍是 Stockfish。
- **保险**：
  - Maia 走出不合法的着，或者算超过 2 秒，就退回同档的 Stockfish 走法，并记一次。
  - 在「将死就在眼前」时，Maia 有时会看不见；这是像人，不修。

**验收**：

- 单元：
  - 权重解码与 lc0 官方给出的一个局面的策略输出对齐（误差 < 1e-3）；
  - 编码对齐 lc0 的平面定义（含易位权、过路兵、50 回合）；
  - 1858 的映射往返。
- **像不像人**：拿 Lichess 公开库里该分段的 2,000 个局面（CC0），测「与真人实际着法吻合率」。目标：Maia ≥ 45%，现在的 Stockfish 档 ≤ 35%（基线这一版先测出来）。
- **阶梯不乱**：沿用 `test-strength.mjs` 的对局法，相邻两档 60–75%，和 v8 的阶梯一个标准。
- **性能**：一步 ≤ 200 ms（CI 的 macOS、Windows 各测）；首屏包不变。

## 2 · I 「人会怎么走」

**做什么**：复盘和分析棋盘的引擎栏下面，多一行「1500 分的人：Nf3 41% · e4 22% · d4 15%」。

- 分段跟你的对局等级分走；没有等级分的用 1500。
- 你走的那步如果是低于 5% 的冷门，标一个「少有人走」。
- 设置 · 高级里可以关。
- 和 10.0 的「教练」一句话结合：「引擎说 −1.2；同水平的人 60% 也会这么走——这是这个分段的常见错误，值得练」。

**验收**：e2e 测试这一行在复盘、分析棋盘出现，并且跟着光标走；文案字数守卫（11.0 U1）不升。
