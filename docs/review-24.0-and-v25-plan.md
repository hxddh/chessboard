### 2.2 · 次要

- **P7 第一盘认输仍掉约 150–170 分**：种子起算（r = 定级，rd 200）按设计工作：1375 定级输给 1056 → 1206（原来 993），1775 输给 1512 → 1622（原来 1330）。真机清单第 5 条「不再低 200–300」勉强过。`SEED_RD` 调到 150 时两例各掉 102、93 分，调到 120 时掉 67、62 分（`fileRating` 实算，第 7 节问题 4）。
- **P8 `openPathAllowed` 的边**：不解析符号链接；Windows 允许 UNC（含 WebDAV 形式，读时会对那台主机发 NTLM）；不拒 `CON.pgn` 这类设备名。都要操作系统或本机进程给出路径，页面脚本只能取、不能塞，路径只签发一次，所以不可利用；记下来，24.1 顺手拒掉 UNC 与设备名。

### 2.3 · 核对过、没有问题的

macOS Apple Event 在 `NSApplicationWillFinishLaunching` 装上，冷启动的文件在页面出现前就排进队列；队列与桥都在主线程，上限 8，路径 ≤ 2047 字节、没有差一；`openPathAllowed` 拒 NUL、`..`、点开头、`\\?\` 与 `\\.\`、`C:a.pgn`，认 `.PGN`；DevTools 补丁在唯一的 `get_CoreWebView2` 处，开关规则与 runner 相同；确认框排队在异常时也会往下走；导入锁没有丢唤醒；`noteClock`、`firstMover`、`moveFact`、`findMotifText`、新对局卡窗口、三语键齐全；今天页的定级作答不重复计；#137 的 restore-keys 在两个工作流里一致。
