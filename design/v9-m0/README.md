# 9.0 M0 设计稿

`docs/v9-0-plan.md` §7 的 M0：5 个关键画面的静态原型，**先给你看、你点头再动代码**（§8 第 2 条）。
全部是假数据，没有应用逻辑；直接用浏览器打开任一 `.html` 即可（`?theme=day` 切到「日」主题）。

所有画面只用一份样式表 `v9.css`——它就是「设计语言 v2」，M1 会把它搬进 `src/web/styles.css`，不是另画一套。
`mock.js` 只做显影：把 `data-icon` 换成 Lucide 图标、把 `data-fen` 画成 CSS 网格棋盘、把着法里的 N/B/R/Q/K 换成棋子小图、画细线曲线与进度环。

## 计划之外我做的决定

1. **今天页加了「最近对局」和「等级分」**：S1 只要求主卡 + 三环 + 继续，但 1440×900 下这三块只占到 y≈560，下面会空出 300 px——正好是 S1 验收要消灭的东西。两块用的都是已有数据，不是新功能。
2. **等级分分成「对局」与「谜题」两个数**：计划说处处叫「等级分」，但这本来就是两个数。见下面待定 2。
3. **主卡加了一行复习事实**（第 2 次复习 · 上次 3 天前 · 连对两次就算学会）：把 SRS 的规则用人话写出来，也填住棋盘旁的空。
4. **抽屉的「一半」= 棋盘下方剩下的全部高度**（至少 260 px），而不是固定 50%：棋盘先按宽、高取较小者，抽屉吃掉其余，这样一半档永远不盖棋盘。
5. **终局时悔棋变灰但不挪位**：「固定 5 格」的意思是位置不变，按钮可用不可用另说。
6. **窄窗里成就徽章从结果行挪到玩家行**：600 宽时结果行放不下分数 + 徽章 + 两个按钮。
7. **「日」主题的强调色改成深黄铜 `#8a5a24`**：8.4 的「日」同时有黄铜 accent 和蓝色主按钮，是两个强调色。
8. **着法里的棋子用 SVG 小图而不是 ♘ 字符**：字符随系统字体变样（Linux 上甚至没有），小图与棋盘同一套。
9. **复盘里的关键时刻：当前那一张用强调色描边**（选中态），其余两张平常。

## 待你定的

1. **训练页的「≤ 8 个主要选择」怎么数**：现在是 1 主按钮 + 复习 + 6 类 = 8；挑战（冲刺 / 连胜）与专项（看 N 步 / 盲走）做成次一级的小按钮收在一张卡里。如果这 4 个也要算，得把它们收成两个「挑战 ›」「专项 ›」入口。
2. **等级分是一个数还是两个**：对局与谜题各有一个（今天页并列，训练页只显示谜题的）。要不要在界面上明确叫「对局等级分 / 谜题等级分」？
3. **今天页第三行**（最近对局 + 等级分）可以接受吗？还是宁可首页更短？
4. **结果条里成就徽章的颜色**：现在是中性灰，不抢「再来一盘」；要不要更醒目？
5. **棋子集的中文名**（经典 / 梅里达 / 栗子 / 凯尔特 / 奇幻 / 立体）还是保留原名（Cburnett / Merida …）？
6. **上一手的黄铜色** `rgba(196,158,72,.42)`：在深格上偏「芥末」，在浅格上偏「麦色」。要不要按 8.4 的 `mark-colour` 色度上限重新量一遍再定？
7. **字体**：截图是 Linux（中文落到文泉驿，没有粗体，所以中文 600 看起来是常规体），真机上会是苹方 / 微软雅黑——§8 第 8 条请你在真机上看一次。
